# Политика конфиденциальности MangaBuff Reader

Дата вступления в силу: 16 августа 2026 года.

## Кратко

MangaBuff Reader не содержит рекламы или аналитики и не собирает данные для разработчика.

## Авторизация и данные сайта

Приложение отображает сайт MangaBuff с помощью Android System WebView. Cookies, авторизация, последняя открытая страница и позиция чтения хранятся локально на устройстве средствами Android.

Обмен данными с MangaBuff происходит напрямую между устройством пользователя и серверами сайта. На обработку данных самим сайтом распространяются правила MangaBuff.

## Обновления

Когда приложение открыто, оно может обратиться к публичному файлу `update.json` в этом репозитории, чтобы узнать номер последней версии. При согласии пользователя APK загружается с GitHub Releases.

Перед установкой проверяются SHA-256, имя пакета, номер версии и цифровая подпись. Установку подтверждает пользователь через стандартный установщик Android.

## Разрешения

Приложение использует доступ в интернет для отображения сайта и проверки обновлений. Разрешение на установку неизвестных приложений используется только для запуска стандартного установщика после действия пользователя.

Приложение не запрашивает доступ к контактам, геолокации, камере, микрофону, журналу звонков или SMS.

## Фоновая работа

MangaBuff Reader не использует постоянный фоновый сервис. После сворачивания WebView и его таймеры приостанавливаются.

## Изменения политики

Актуальная версия политики публикуется в этом файле. Существенные изменения могут быть указаны в описании нового релиза.
