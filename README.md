# 📖 MangaBuff Reader

### MangaBuff в формате удобного Android-приложения

## О приложении

**MangaBuff Reader** открывает MangaBuff как отдельное Android-приложение: без необходимости каждый раз искать вкладку браузера, с сохранением авторизации, последней страницы и позиции чтения.

Приложение предназначено для персонального использования и не содержит рекламы, аналитики или фоновых сервисов.

## ✨ Возможности

- сохранение авторизации и cookies средствами Android WebView;
- запоминание последней открытой страницы;
- восстановление позиции чтения;
- автоматический полноэкранный режим внутри главы;
- масштабирование изображений жестами;
- тёмное оформление и компактная панель навигации;
- выбор и загрузка файлов через системные средства Android;
- автоматическая проверка обновлений раз в сутки при открытом приложении;
- ручная проверка через меню **⋮ → Проверить обновления**;
- отображение номера версии и списка изменений.

## 🔐 Безопасные обновления

Перед передачей скачанного APK системному установщику приложение проверяет:

1. контрольную сумму SHA-256;
2. имя пакета приложения;
3. номер новой версии;
4. цифровую подпись APK.

Если хотя бы одна проверка не пройдена, установка не запускается. Android всегда показывает стандартное окно установки — приложение не устанавливает обновления скрытно.

## 📲 Установка

1. Откройте раздел [**Releases**](https://github.com/EnoTik20/mangabuff-reader/releases).
2. Выберите последний релиз.
3. В разделе **Assets** скачайте файл `MangaBuff-Reader-vX.X.X.apk`.
4. Откройте APK на Android.
5. При необходимости разрешите установку приложений из браузера или файлового менеджера.
6. Нажмите **Установить**.

При обновлении не удаляйте предыдущую версию: новый APK устанавливается поверх неё и сохраняет авторизацию, cookies и настройки.

## 📱 Совместимость

- Android 6.0 и новее;
- смартфоны и планшеты;
- актуальный Android System WebView или Google Chrome;
- подключение к интернету.

| Разрешение | Для чего используется |
