## Версия 1.0.1

Hotfix авторизации через Яндекс и VK. Внутренний номер сборки — `7`.

## Возможности

- авторизация MangaBuff, включая Яндекс и VK, выполняется внутри приложения, а cookies сохраняются локально средствами Android WebView;
- запоминаются последняя страница и позиция чтения;
- позиция восстанавливается после полной загрузки изображений и изменения высоты главы;
- глава автоматически открывается в полноэкранном режиме;
- верхняя панель сайта, рекламные контейнеры, Telegram-плашки, подарок и нижняя панель MangaBuff скрываются во время чтения;
- компактная кнопка `☰` настраивается по размеру и цвету;
- прогресс главы показывается только при открытой панели чтения;
- избранное открывается поверх главы и содержит обложки, текущую главу и автоматически обновляемый прогресс;
- из панели чтения доступны список глав, закладка и настройки сайта;
- главу можно открыть во внешнем браузере или отправить через системное меню «Поделиться»;
- меню **Ещё** оформлено как собственная закруглённая нижняя панель;
- обновления проверяются вручную или автоматически раз в сутки только при открытом приложении;
- перед установкой APK проверяются SHA-256, пакет, номер версии и цифровая подпись.

В приложении нет аналитики, рекламных SDK, собственной рекламы, постоянного фонового сервиса или скрытой установки обновлений.

## Установка

1. Откройте [релиз `v1.0.1`](https://github.com/EnoTik20/mangabuff-reader/releases/tag/v1.0.1).
2. Скачайте `MangaBuff-Reader-v1.0.1.apk` или ZIP-пакет.
3. Откройте APK на Android и подтвердите установку.
4. Если Android попросит разрешение, разрешите установку приложений для браузера или файлового менеджера, из которого открыт APK.

При обновлении не удаляйте предыдущую версию: установка поверх неё сохраняет авторизацию, избранное и настройки.

SHA-256 финального APK:

```text
0996f0188aa3d789be2167ef2095aa29bcf61785263d4afee56234e45b0710f7
```

## Совместимость

- Android 6.0 и новее;
- target SDK 35;
- актуальный Android System WebView или Google Chrome;
- подключение к интернету.

## Разрешения

| Разрешение | Для чего используется |
| --- | --- |
| Интернет | Открытие MangaBuff, загрузка обложек и проверка обновлений |
| Установка неизвестных приложений | Передача проверенного APK стандартному установщику только после подтверждения пользователя |

Приложение не запрашивает доступ к контактам, геолокации, камере, микрофону, журналу звонков или SMS.

## Сборка из исходников

Проект рассчитан на Android Studio с JDK 17 и Android SDK 35.

1. Клонируйте репозиторий и откройте его корневую папку в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Для отладочного APK выберите **Build → Build APK(s)**.
4. Для собственного release-APK используйте свой ключ подписи.

Файл `keystore.properties`, папка `signing` и любые файлы `*.jks` исключены из Git. Оригинальный приватный ключ релиза не публикуется: он нужен для безопасной установки будущих версий поверх `1.0.1`.
